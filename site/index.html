03 ABOUT

关于本项目

本项目是一个纯静态、零服务器的会议论文索引站,灵感来自已离线的 Lex Jansen 索引站,并参考了 clinyun.com/ppi 与 clinstandards.org 的资源组织方式。

动态更新机制:站点本身是静态 HTML,通过 GitHub Actions 定时(每月 + 会议季后)运行 Python 抓取脚本,从各会议官网获取最新论文,更新数据后自动重新部署到 GitHub Pages。无需任何服务器或数据库。

版权说明:本站仅做索引与链接,论文 PDF 版权属于各会议与作者,点击直达官方原始 PDF。如需镜像或抓取会员专有内容,请先获得授权。
