02 ABOUT

About This Project

ClinProc is a fully static, serverless index of conference papers, inspired by the now-offline Lex Jansen index and the resource organisation of clinstandards.org. The interface draws on Semantic Scholar and Hugging Face Papers.

How it stays current: the site is plain HTML; a GitHub Actions workflow runs the Python scraper on a schedule (monthly + after conference seasons), commits the refreshed JSON and redeploys to GitHub Pages. No servers, no databases.

Copyright: this site only indexes and links. PDF copyright belongs to the conferences and authors; links go straight to the official originals. Ask for permission before mirroring or scraping members-only content.
